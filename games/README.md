# 🎮 115 鯉魚市集・攤位小遊戲

市集網站是入口：在攤位介紹按「🎮 玩線上版」，就會用全螢幕打開這裡的遊戲。

## 資料夾

| 資料夾 | 是什麼 |
| --- | --- |
| `_kit/` | 共用工具包（開始畫面、過關畫面、音效、回市集、通關章）。不用改。 |
| `_template/` | 遊戲範本。新遊戲就複製這個資料夾。 |
| `stall-08/`～`stall-19/` | 10 個遊戲：第 8、9、10、11、12、13、14、17、18、19 攤（過關會蓋線上通關章）。 |
| `stall-06/`、`stall-15/`、`stall-16/` | 3 個創作小工具：畫貼紙、鑽石畫、聖誕樹（完成可存圖，不算通關章）。 |

## 學生可以改什麼

1. **設定**：每個 `game.js` 最上面的 `CONFIG`（遊戲名稱、玩法說明、時間、難度、組員署名 `credit`）。
2. **圖片**：畫好的圖存成透明 PNG（最長邊 512 像素內、英文檔名），放進該攤的 `assets/` 資料夾，告訴老師要換哪個東西。
3. **音效**：目前用瀏覽器合成的聲音；想用自己錄的，存成 .mp3 放進 `assets/`。

## 規則

- 過關條件要和現場攤位一樣；過關時程式呼叫 `LIYU.clear(分數)`，市集就會蓋「線上通關章」。
- 一輪 1～3 分鐘，手機直拿也要能玩，按鈕不要太小。
- 不連外部網站、不要登入、不收姓名。
- 圖和聲音要是自己做的，不用網路上找的圖或卡通角色。

## 試玩

- 單獨打開：`https://lester47.github.io/my-island/games/stall-11/`
- 在市集裡打開：點攤位 → 展開攤位介紹 → 「🎮 玩線上版」。
- 改完 `CONFIG` 後，請在 `index.html` 和 `game.js` 裡把 `?v=` 後面的版本號一起換新，手機才不會用到舊檔。
